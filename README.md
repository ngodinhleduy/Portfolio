# Portfolio

Vite + vanilla JS + GSAP + Lenis.

```
npm install
npm run dev
```

Structure:
- `src/styles/tokens.css` design tokens (colors, type scale, spacing, easing)
- `src/lib/smooth-scroll.js` Lenis + ScrollTrigger sync
- `src/lib/reveal.js` split-text reveals, fade reveals, parallax via data attributes
- `src/lib/preloader.js` counter preloader
- `src/lib/cursor.js` custom cursor + magnetic elements
